## Contributing to Translations

We welcome community improvements to existing translations and proposals for new languages.

1. Please read [CONTRIBUTING.md](../../CONTRIBUTING.md) for contribution guidelines.
2. Ensure technical terms (such as *Model Context Protocol*, *ETag*, *AbortController*, and CLI commands) remain technically accurate and consistent with the English source.
3. For right-to-left languages (e.g. Persian, Arabic), preserve `<div dir="rtl" align="right">` wrappers and format code blocks in clean LTR.
