## 💡 समस्या और समाधान

डेवलपर मूल्यांकन आज दो टूटी हुई चरम सीमाओं के बीच फंसा हुआ है:

- **दिखावटी मेट्रिक्स (Vanity Metrics)** — कृत्रिम रूप से बढ़ाई गई कमिट स्ट्रीक्स, खाली फ़ोर्क्स, और भाषा आँकड़े बढ़ाने के लिए बनाए गए खिलौना रिपॉजिटरी।
- **AI मतिभ्रम (LLM Hallucinations)** — बिना किसी ठोस प्रमाण के ब्लैक-बॉक्स स्कोरकार्ड्स और सामान्य विवरण।

**GitIntel** तीसरा और प्रामाणिक मार्ग है: वास्तविक GitHub आर्टिफैक्ट्स से प्राप्त 100% अवलोकन योग्य और निश्चित इंजीनियरिंग सिग्नल्स।

## 🚀 मुख्य विशेषताएँ

### 1. 🌟 GitHub प्रोफाइल README जेनरेटर
अपने `username/username` पेज को सत्यापित इंजीनियरिंग उपलब्धियों के शोकेस में बदलें:
- वास्तविक तकनीकी डेटा के आधार पर स्वचालित रूप से `README.md` उत्पन्न करता है।
- परीक्षण प्रथाओं, CI/CD पाइपलाइनों और रिलीज़ इतिहास को उजागर करता है।
- लावारिस फ़ोर्क्स को फ़िल्टर करता है; केवल आपके मौलिक और प्रभावी कार्य को प्रदर्शित करता है।

### 2. 🤖 नेटिव MCP सर्वर (Model Context Protocol)
AI सहायकों को बिना रेट लिमिट खत्म किए GitHub प्रोफाइलों का विश्लेषण करने में सक्षम बनाता है:
- JSON-RPC टूल्स: `gitintel_analyze_profile`, `gitintel_get_signals`, `gitintel_generate_profile_readme`, `gitintel_get_ai_prompt`।
- **Claude Desktop**, **Cursor**, **Antigravity** और किसी भी MCP-सक्षम एजेंट के साथ पूरी तरह संगत।

### 3. 📊 छह सत्यापन योग्य इंजीनियरिंग सिग्नल्स

| सिग्नल | GitIntel क्या निरीक्षण करता है | ईमानदार तकनीकी सीमा |
| :--- | :--- | :--- |
| 🔄 **कोड विकास (Code Evolution)** | पुश और अपडेट टाइमस्टैम्प्स की नवीनता | कमिट्स की कुल संख्या का विश्लेषण नहीं करता |
| 🛡️ **रखरखाव (Maintenance)** | अपडेट की आवृत्ति; संग्रहीत रिपॉजिटरी "पूर्ण" चिह्नित | निष्क्रियता का अर्थ खराब रखरखाव नहीं है |
| 🧪 **परीक्षण साक्ष्य (Testing Evidence)** | टेस्ट डायरेक्टरी और CI वर्कफ़्लोज़ का Git ट्री स्कैन | परीक्षण चलाता नहीं है और न ही कवरेज मापता है |
| 🤝 **सहयोग (Collaboration)** | सत्यापित PR/Issue विभाजन, योगदानकर्ताओं की संख्या, इनकमिंग फ़ोर्क्स | बाहरी योगदान विश्लेषण के लिए GraphQL आवश्यक है |
| 📖 **दस्तावेज़ीकरण (Documentation)** | README त्रि-स्तरीय पहचान, GitHub Pages, Wiki, LICENSE | भाषा या गद्य की गुणवत्ता का मूल्यांकन नहीं करता |
| 📦 **रिलीज़ और डिलीवरी (Release & Delivery)** | सत्यापित GitHub रिलीज़ और सेमांटिक वर्ज़न टैग्स | केवल सक्रिय मूल रिपॉजिटरी तक सीमित |

### 4. 💼 रिक्रूटर-रेडी रेज़्यूमे और पोर्टफोलियो
- तकनीकी नौकरी आवेदनों के लिए साक्ष्य-आधारित Markdown सारांश निर्यात करें।
- टोकन-अनुकूलित संदर्भ के लिए एक-क्लिक **"AI प्रॉम्प्ट के रूप में कॉपी करें"**।

## ⚡ त्वरित शुरुआत

### पूर्वापेक्षाएँ

| उपकरण | न्यूनतम संस्करण |
| :--- | :--- |
| Go | 1.26 |
| Node.js | 24 |
| npm | 11 |

### Windows — वन-क्लिक लॉन्चर
```bat
git clone https://github.com/Hosseinghorbani0/GitIntel.git
cd GitIntel
run.bat
```

### Linux और macOS
```bash
git clone https://github.com/Hosseinghorbani0/GitIntel.git
cd GitIntel

# टर्मिनल 1 — बैकएंड
cd backend
go run ./cmd/server

# टर्मिनल 2 — फ्रंटएंड
cd frontend
npm ci
npm run dev
```

### GitHub टोकन (वैकल्पिक)
```bash
cp .env.example .env
# .env संपादित करें और सेट करें: GITHUB_TOKEN=ghp_your_token_here
```

### Claude Desktop से कनेक्ट करें
अपनी `claude_desktop_config.json` फ़ाइल में जोड़ें:

```json
{
  "mcpServers": {
    "gitintel": {
      "command": "go",
      "args": ["run", "./backend/cmd/mcp"],
      "cwd": "/path/to/GitIntel"
    }
  }
}
```

## 🏗️ सिस्टम आर्किटेक्चर

```text
┌─────────────────────────────────────────┐
│      React 19 + Vite (TypeScript)       │
│         http://localhost:5173           │
└──────────────────┬──────────────────────┘
                   │ proxy /api
┌──────────────────▼──────────────────────┐
│          Go 1.26 Backend                │
│        http://localhost:8080            │
│  LRU कैश (1,000 प्रविष्टियाँ) +          │
│  GitHub क्लाइंट (ETag · Rate Guard)     │
└──────────────────┬──────────────────────┘
                   │ REST + ETag 304
        ┌──────────▼──────────┐
        │   GitHub REST API   │
        └─────────────────────┘
```

**इंजीनियरिंग हाइलाइट्स:**
- **शून्य-आवंटन कैश** — 1,000-प्रविष्टि LRU कैश और अपरिवर्तनीय स्नैपशॉट।
- **सक्रिय रेट लिमिट सुरक्षा** — अप्रत्याशित थ्रॉटलिंग से बचने के लिए 10-कॉल सुरक्षा बफर।
- **सशर्त ETag अनुरोध** — HTTP 304 प्रतिक्रिया **शून्य** रेट लिमिट कोटा खर्च करती है।
- **रेस-कंडीशन प्रूफ UI** — `AbortController` के माध्यम से अनुरोध रद्दीकरण।
- **द्विभाषी व सुलभ इंटरफ़ेस** — फारसी (RTL) और अंग्रेजी दोनों का पूर्ण समर्थन।
- **लोकलहोस्ट सुरक्षा आइसोलेशन** — बैकएंड केवल `127.0.0.1:5173` से अनुरोध स्वीकार करता है।

## 🔒 सुरक्षा और गोपनीयता

- GitIntel पूरी तरह से **स्थानीय (localhost)** पर चलता है। आपका टोकन और कोड डेटा कभी भी आपके सिस्टम से बाहर नहीं जाता।
